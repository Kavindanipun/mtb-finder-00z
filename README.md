# MTB Staff Stock Finder V10

45 original image-proof records (including images 37-45), 217 original Excel source cells, and 30 staff model entries.

## Deploy on GitHub Pages
Upload `index.html`, `404.html`, and `README.md` to the repository root (not the ZIP); deploy the `main` branch root through Settings > Pages.

## Matching
Each photo keeps its own model list and image. Excel matching uses members of one source cell, including parenthetical models. All candidate matches require image-backed evidence. Distinct cells and photos stay separate; no cross-row transitive matching.

Note: model spellings follow user-provided lists, including any names awaiting manual confirmation.
